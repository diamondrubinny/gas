Gas Safety Manager v2.8.3 — fix: intermittent "Cookie check failed" (nonce) errors.

FIX in v2.8.3:
- "בדיקת עוגיות נכשלה" (rest_cookie_invalid_nonce) no longer forces a manual refresh.
  1) Login now returns a nonce valid for the NEW session (set_logged_in_cookie applied
     in-request before wp_create_nonce) -> first call after login works.
  2) The SPA auto-recovers from an expired/rotated/cached nonce: on that error it pulls
     a fresh nonce via admin-ajax (action=gsm_nonce, cookie-auth, no REST nonce needed)
     and retries the request ONCE. Safe: the nonce gate runs before the handler, so the
     rejected call never executed -> no double-submit.
  3) A heartbeat refreshes the nonce on a 12-min timer and on tab refocus, so idle tabs
     don't fail on the first action.
- No tables/behaviour change — DB stays v6 (safe "Replace current with uploaded").
