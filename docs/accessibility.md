## בדיקות (רצות ב-CI על WordPress 6.4.5 ו-latest)
```bash
BASE=http://127.0.0.1:8899 USER_NAME=admin PASS='…' node tests/e2e/a11y-audit.js --report a11y.json
```
```bash
BASE=http://127.0.0.1:8899 USER_NAME=admin PASS='…' node tests/e2e/keyboard-a11y.js
```
- `a11y-audit.js` נכשל על כל הפרה. הדוח המלא נשמר כ-artifact (`a11y-report-wp-*`).
- `keyboard-a11y.js` בודק: התחברות במקלדת, קישור הדילוג, כותרת ופוקוס במעבר מסך, חלון קופץ (dialog / trap / Esc / החזרת פוקוס), שדה חובה, העלאת קבצים במקלדת, live regions, ועמוד ה-QR.

## מה עדיין דורש בדיקה ידנית ואישור מקצועי
1. **בדיקה עם קוראי מסך:** NVDA או JAWS ב-Windows, VoiceOver ב-iOS ו-macOS, ו-TalkBack. לבדוק במיוחד: טפסים, טבלאות ארוכות, תפריט הקבוצות, ההדפסה ועמוד ה-QR בטלפון.
2. **בדיקה של מורשה נגישות** ואישור **הצהרת הנגישות**. הטיוטה נמצאת ב-`themes/gas-safety-theme/templates/template-accessibility.php`, ועודכנה לפי מה שבוצע בפועל. צריך להשלים בה את פרטי רכז הנגישות, זמן מענה ותאריך הבדיקה הידנית.
3. **התוכן עצמו:** קבצים שמשתמשים מעלים (PDF, תמונות) לא נבדקים לנגישות.
4. **רכיבי צד שלישי** שיותקנו באתר בעתיד.
